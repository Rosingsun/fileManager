## 图片分类准确率重构（fileDeal）

根因：`models/clip-prompts*.json` 是 FNV 哈希 + sin/cos 造的**伪嵌入**（标注 PLACEHOLDER），
CLIP 零样本实际在随机猜；另有 RGBA 按 3 通道解析、letterbox 黑边、温度放大噪声、
评估体系空转（0 张 fixture、脚本失败后 exit 0）等问题。

- **地基**：HF 直连不通，改走 hf-mirror + curl 断点续传预下载到
  `scripts/_clip_text_gen/.cache/`，用 `CLIPTextModelWithProjection` 生成真实文本嵌入。
  `prompts-data.mjs` 重写为纯英文肯定句（原含中文与 "not a X" 否定式）。
  类内余弦从 0.04 → 0.90(b32)/0.79(l14)。产物仍是随仓库 JSON，运行时完全离线。
- **运行时**：`classificationPreprocess.ts` 改 EXIF 转正 + 短边缩放 + 中心裁剪 + 强制 3 通道；
  `clipEngine.ts` 改类别原型余弦 + maxBlend + 学出类别偏置 + softmax 温度；
  `calibration.ts` 重写为 v2；`pipeline.ts` 去掉条件 ImageNet 融合与成对消歧，
  置信度改为逻辑回归「判对概率」；`clipClassifier.ts` 校验 `embeddingsSource` 与向量维度，
  伪嵌入/模型错配直接拒绝推理。
- **评估体系**：Wikimedia Commons 构建 144 张带标签图（`manifest.json` 用相对路径）；
  `extract-classification-features.ts` 缓存 CLIP 嵌入/ ImageNet 概率；
  `calibrate-classification.mjs` 做 5 折分层交叉验证网格搜索（温度/maxBlend/类别偏置/
  融合权重/弃判阈值/置信度/复核阈值），`eval-classification.mjs` 改为链路体检，
  `run-classification-eval.mjs` 改为端到端评估并输出 ECE。新增 npm scripts：
  `gen:clip-prompts`/`fixtures:classify`/`features:classify`/`calib:classify`。
- **结论**：基线 12.5% / 13.2%（随机 11.1%）→ 端到端 **88.2% / 91.7%**（127/144、132/144），
  CV 88.2% / 91.0%，ECE fast 0.0786 / max 0.0121。交叉验证判定 ImageNet 融合权重最优为 0，
  两个预设已移除辅助模型，预设说明同步更新。
- **前端**：结果页新增 Top3 判定依据浮层、判对可信度分级、按分类/状态/文件名筛选、
  「待人工复核」队列（低于 reviewBelow 标记 uncertain）、统计卡与人工修正标记。
- **关键约定**：离线标定脚本的打分公式必须与运行时 `scoreClipWithConfig` 严格一致；
  `models/clip-prompts*.json` 必须保持 `embeddingsSource=clip-text-model`；
  改 prompt/模型/评估集后必须重跑完整标定流水线。详见 `models/EVAL_BASELINE.md`。
