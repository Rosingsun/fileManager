## 相似照片检测重构（fileDeal）

根因：`main.ts` 内联的"pHash"实为 8×8 均值哈希（aHash），无 DCT/色彩/结构、无 EXIF 转正；
贪心锚点分组（先占先得、组内不互验）导致链式误判；O(n²) 字符串比较、串行整文件读取、
取消只置空窗口指针（假取消）；`services/similarityService.ts` 是死代码；已下载的 CLIP
视觉模型零引用；评估集与基线为空。

- **引擎**（`electron/main/utils/similarityUtils.ts`）：真 pHash（32×32 可分离 DCT 前 8×8 取中位数）
  + 9×8 梯度 dHash + 4×4 颜色布局 + 宽高比 + 拉普拉斯清晰度；一次 EXIF 转正解码产出全部指纹。
  打分拆成 `computePairParts` / `scorePairParts` 纯函数，离线标定与运行时共用同一实现。
- **分组**（`utils/similarityGrouping.ts`）：并查集连通分量替代贪心；exact 用 MD5 分桶 O(n)；
  逐对 `pairScores` + 判定依据；`safeToDelete = tier !== 'scene'`。
- **scene 隔离**：CLIP 语义组只从未进入 exact/near 安全组的图片中生成，独立 DSU，
  与可删除组零交叉——批量删除不可能误删同场景照片。
- **性能/取消**（`services/similarityService.ts`）：4~6 并发解码池；每任务边界检查取消标志；
  分阶段进度（scanning/hashing/comparing/semantic）+ `stagePercent`；RAW 解码失败保留 MD5 并标记。
- **标定**：`scripts/gen-similarity-fixtures.ts` 用 144 张评估图程序化生成 1728 张变换
  （近重复 9 种、同场景 3 种）；`calibrate-similarity.ts` 网格搜索 2160 组，
  写回 `models/similarity-calibration.json`：pHash .6 / dHash .1 / color .25 / aspect .05，
  阈值 80，pDist ≤18，cDist ≤0.35，语义阈值 0.825。
- **实测**（`eval:similarity`，1872 张）：近重复变体检出 **99.54%**，跨源误合并 13/11147 对
  （0.12%），scene 交叉 0，合成隔离 PASS，1.75M 对比较 **0.3s**，取消响应 6ms，
  指纹提取 2.6s（并发 6）。旧 aHash@90 为 94.91% / 误判 0.15%。
- **前端**：Setup 改三档检测范围（完全重复/近重复/同场景），阈值预设改为 80/86/92（默认 86）；
  结果页加档位徽章、逐对相似度区间、档位筛选、scene 组禁选并在删除/移动前二次过滤；
  进度页支持 semantic 阶段与细粒度百分比。
- **修复**：`SimilarityScanSetup.tsx` 仍 import 已移除的 `ALGORITHM_OPTIONS` 导致
  `SyntaxError: does not provide an export named 'ALGORITHM_OPTIONS'`，已改接 `DETECTION_MODE_OPTIONS`
