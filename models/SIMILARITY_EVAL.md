## 与旧实现的对比

| 指标 | 旧 aHash 8x8（阈值 90） | 新指纹 + 标定参数 |
|---|---|---|
| 近重复变体检出率 | 94.91% | **99.23%** |
| 不同照片误判率 | 0.15% | **0.04%** |
| 同类别不同照片误判率 | — | 0.32% |
| 旧算法在误判≤1%下的最优检出 | 97.45% @ 86 | — |

说明：正样本为同一原图经 JPEG 压缩、亮度/饱和度调整、灰度、缩放、轻微模糊、10% 裁剪等变换；
负样本为不同原图（含同类 hard negative）及跨源的变换组合。误判意味着「批量删除会误删照片」，
因此网格搜索以误判率 ≤ 0.5% 为硬约束再最大化检出率。

```json
{
  "weights": {

    "color": 0.25,
    "aspect": 0.05
  },
  "threshold": 80,
  "maxPHashDistance": 18,
  "maxColorDistance": 0.35,
  "semanticThreshold": 0.825

```

- 网格搜索 2160 组参数；打分函数与运行时 `scorePairParts` 为同一实现，不存在离线/线上漂移。
- 大幅裁剪/镜像/强调色等 scene 变体被 near 档顺带覆盖 33.80%（这些仍属同一张照片，覆盖不算误判）。

## 三档语义与删除隔离

| 档位 | 判定依据 | 允许批量删除 |
|---|---|---|
| exact | MD5 字节完全一致 | 是 |
| near | DCT 感知哈希 + 梯度哈希 + 颜色布局 + 宽高比 | 是 |
| scene | CLIP 视觉嵌入余弦（仅未进入安全组的图片） | **否** |

CLIP 语义阈值标定：阈值 0.825；同图大幅变换余弦均值 0.905、同类不同照片 0.608、跨类 0.457；语义正样本检出 89.8%，负样本误判 0.2%。

scene 组与可删除组在并查集层面完全隔离（只对未被 exact/near 组收录的图片生成），
因此「同场景的两张不同照片」永远不会进入批量删除队列。

## 端到端验证（`npm run eval:similarity`）

在 144 张原图 + 1728 张变换（共 1872 张）上跑真实分组逻辑：

| 指标 | 结果 |
|---|---|
| 近重复变体检出率 | **99.54%**（1290/1296） |
| 同场景变体被 near 档顺带覆盖 | 34.72%（150/432） |
| 跨源误合并 | 7 组 / 13 对（占 11147 个负样本对的 0.12%） |
| scene 与安全组交叉 | 0 张 |
| 档位标记错配 / 缺少逐对分数 | 0 / 0 |
| 合成 scene 隔离断言 | PASS |
| 1.75M 对比对耗时 | 0.3s |
| 取消响应 | 6ms，取消后比对对数 0 |

指纹提取 1872 张耗时 2.6s（并发 6）。跨源误合并多为同类别、构图高度相似的素材图，
因此删除前仍需用户逐组确认保留项——工具只负责把候选收拢，不代替人工判断。

## 复现

```bash
npm run sim:fixtures       # 生成变换样本（可重复）
npm run calib:similarity   # 网格搜索 + 语义阈值标定 + 写回标定文件
npm run eval:similarity    # 端到端分组质量验证（含取消、并发、隔离断言）
npm run check:similarity   # 链路体检
```
