# 文件整理工具

跨平台桌面文件整理工具，使用 Electron + React + TypeScript + Vite 构建。

## 功能特性

### 📁 智能文件分类整理
- **按文件类型（扩展名）**：自动将文件按扩展名分类到对应文件夹
- **按修改日期**：支持按年/月/日三级时间维度分类文件
- **按文件大小**：自定义文件大小分类范围（如：小/中/大）
- **自定义正则表达式**：灵活配置个性化分类规则
- **文件提取**：从子目录中提取指定类型文件到当前目录，支持通过下拉多选扩展名或选择类别、指定大小范围进行筛选；提供“全部/取消全部”按钮快速选中当前类型下所有后缀。

### 🔍 实时预览
- **三种视图模式**：列表视图、树形视图、网格视图自由切换
- **预览整理结果**：执行前预览文件移动效果
- **冲突处理**：支持跳过、覆盖、重命名三种冲突解决策略

### 🖼️ 图片查看器与编辑
- **流畅浏览**：支持缩放（20%-500%）、旋转、水平/垂直翻转
- **信息展示**：显示EXIF信息、颜色调色板
- **元数据管理**：支持标签和描述的编辑与保存
- **快捷操作**：键盘快捷键支持（方向键导航、R旋转、F切换视图等）
- **编辑功能**：选中图片可在弹出编辑器中调整颜色、亮度、对比度、饱和度、色相、曝光
  - 支持裁切(输入坐标/大小)、旋转、水平/垂直翻转
  - 用户可保存预设并应用；内建预设支持批量操作
  - 支持格式转换（JPEG/PNG/WebP/BMP/TIFF）和压缩，单图或批量
  - 压缩时展示单张预估大小
  - 批量操作可在列表中勾选多项，工具栏出现“批量编辑”按钮

### 🤖 AI智能图片分类
- **真实零样本 CLIP**：B/32（快速预览）与 L/14（最高精准，5 裁剪 TTA）两个视觉模型，
  搭配由 CLIP 文本编码器预计算的**真实文本嵌入**（`clip-prompts*.json`），输出统一 **9 大类**。
  文本嵌入随仓库提供，运行时完全离线；参数由 144 张标注图的 5 折交叉验证标定。
- **九大类**：人物、动物、自然风景、城市建筑、室内、食物、交通工具、截图、其他。
- **预处理**：EXIF 转正 → 短边等比缩放 → 中心裁剪 → 强制 3 通道 → CLIP 官方 mean/std，
  与 CLIP 官方预处理对齐，不产生 letterbox 黑边。
- **准确率**：评估集 Top-1 快速预览 88.2%、最高精准 91.7%（重构前伪嵌入基线仅 12.5% / 13.2%）。
- **结果可解释**：展示判对可信度（经逻辑回归校准）与 Top3 九类相对分布；
  低可信结果标记「待复核」，支持按分类/状态/文件名筛选与人工修正分类。
- 详见 [评估基线](models/EVAL_BASELINE.md) 与 [模型说明](models/README.md)。

### 🔍 相似照片检测
- **智能检测**：基于感知哈希算法检测重复或相似照片
- **分组展示**：将相似照片分组显示，便于批量处理
- **进度追踪**：实时显示扫描进度和当前处理文件
- **节省空间**：帮助清理冗余文件，释放存储空间

### 📊 文件浏览与管理
- **目录导航**：支持多层级目录浏览
- **文件筛选**：按类型筛选（图片、视频、音频、文档、压缩文件等）
- **历史记录**：自动记录访问过的目录，支持快速跳转
- **子目录包含**：可选是否包含子目录文件

### ☁️ 云盘管理（多 Provider 架构）
- **多云适配**：抽象 `CloudProvider` 接口，本期落地**阿里云盘**，预留 OneDrive / WebDAV / S3 等扩展位
- **凭证安全**：refresh_token 通过 Electron `safeStorage` 加密落盘（macOS Keychain / Windows DPAPI / Linux kwallet），与平台用户凭证物理隔离
- **Token 自动续期**：每次请求前自动用 refresh_token 续期 access_token，并 rotate 持久化
- **分片上传 + 快速上传**：16 MB 分片，支持 SHA1 秒传，上传进度实时推送
- **独立管理页**：顶部 Tab「云盘」提供目录浏览、批量上传、新建文件夹、重命名、删除、移动、获取下载链接
- **⚠️ 风险提示**：阿里云盘未对个人开发者开放官方 API，本集成通过社区维护的非官方协议实现，接口随时可能变更

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

这将启动 Electron 应用和 Vite 开发服务器。

#### Windows 用户

在 Windows 系统上，您可以双击运行 `dev.bat` 文件，或在命令提示符/PowerShell 中执行：

```bash
dev.bat
```

或

```powershell
.\dev.bat
```

这将执行相同的开发启动命令。

### 构建应用

```bash
# 构建生产版本
npm run build

# 打包为可执行文件
npm run dist
```

## 项目结构

```
file-organizer/
├── electron/           # Electron 主进程代码
│   ├── main/          # 主进程入口、IPC 处理器与 services/utils
│   └── preload/       # 预加载脚本
├── src/               # React 渲染进程
│   ├── components/    # React 组件（统一出口 index.ts，各功能域分子目录）
│   ├── hooks/         # 自定义 Hooks（统一出口 index.ts）
│   ├── stores/        # 状态管理 Zustand（统一出口 index.ts）
│   ├── utils/         # 工具函数（统一出口 index.ts）
│   ├── types/         # TypeScript 类型定义
│   ├── App.tsx        # 应用主体
│   ├── ThemedApp.tsx  # 主题与全局配置入口壳
│   └── main.tsx       # 渲染进程入口
├── backend/           # 自建认证与业务 API
├── scripts/           # 构建、模型评估与规范校验脚本
├── docs/              # 专题文档
├── models/            # AI 模型与标签文件
└── public/            # 静态资源
```

跨层导入必须走 `utils` / `hooks` / `stores` / `components` 各自的 `index.ts`，禁止直连具体模块；
执行 `npm run check:imports` 可校验全量导入是否符合该规则。

## 使用说明

### 文件整理

1. **选择目录**：点击"选择目录"按钮，选择要整理的文件夹
2. **选择分类方式**：在控制面板中选择分类规则（按类型/日期/大小/自定义）
3. **预览结果**：点击"预览整理结果"查看文件移动预览
4. **开始整理**：确认无误后点击"开始整理"执行文件整理

### 图片分类

1. `models/clip-prompts.json` 与 `clip-prompts-l14.json`（真实 CLIP 文本嵌入）已随仓库提供，无需生成。
2. 在应用内选择预设并下载对应视觉 ONNX：快速预览用 `clip-vit-b32-vision-quant.onnx`（约 85MB），
   最高精准用 `clip-vit-l14-vision-quant.onnx`（约 293MB）；也可执行 `npm run download:models`。
3. 运行 `npm run eval:classify` 做一次链路体检（校验嵌入来源、维度、标定与评估集）。
4. 选择包含图片的目录，点击「开始分类」；在结果页按分类/状态筛选、查看 Top3 依据并人工修正。

> 更换 prompt、模型或评估集后，请依次运行 `fixtures:classify` → `features:classify` →
> `calib:classify` → `eval:classify-run` 重新标定，详见 [模型说明](models/README.md)。

### 相似照片检测

1. 配置扫描目录和相似度阈值
2. 点击"开始扫描"检测相似照片
3. 查看检测结果，分组管理相似照片
4. 选择保留或删除重复文件
